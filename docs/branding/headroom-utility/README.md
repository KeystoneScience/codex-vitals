# Headroom utility icon

Direction: a plain white functional symbol showing remaining quota across three accounts. White quota bars on a black preview canvas. Generated using the built-in imagegen tool. This supersedes the decorative h logo direction; it is a design preview, not yet an installed menu-bar resource.

## Final generation prompt

Create an extremely simple monochrome desktop utility icon. This is a pristine flat vector-style pictogram, no texture anywhere.
IMPORTANT: the whole canvas is SOLID OPAQUE BLACK #000000. No transparency, no alpha channel, no background removal. Every pixel is opaque.
Centered on that black canvas: exactly three identical horizontal rounded-rectangle outlines in PURE WHITE #FFFFFF, neatly stacked with equal spacing. Each outline contains a white horizontal fill bar inset from its border by a clear black gap. Top fill is 75% width, middle fill is 45%, bottom fill is 20%. All unfilled areas and all gaps are perfectly uniform solid black. The three meters communicate remaining usage capacity across accounts.
Use bold clean uniform white outline strokes, moderate corner radius, crisp smooth edges, simple symmetric spacing. The overall symbol occupies about 64% of canvas width and 48% of canvas height, centered both horizontally and vertically. Square image.
This should look like a tiny functional macOS utility toolbar icon enlarged cleanly. Absolutely no brand mark, no lettering, no text, no typography, no labels, no battery nubs, no dots, no decorative features, no grain, no grit, no scratches, no splashes, no shading, no gradients, no glow, no 3D, no shadows, no mockup. Just three clean white partially filled usage meters on perfectly flat pure black.
